PHẦN II. Câu trắc nghiệm đúng sai (4 câu)

Câu 13: Cho hàm số $f(x) = 8x^3 - 6x^2$.

a) Đạo hàm $f'(x) = 24x^2 - 12x$.
b) Một nguyên hàm $F(x) = 2x^4 - 2x^3 + 5$.
c) $\int f(x)dx = \int 8x^3 dx + \int 6x^2 dx$.
d) Họ nguyên hàm là $2x^4 - 3x^3 + C$.

Câu 14: Cho hàm số $f(x) = \sin x - \cos x$.

a) $f'(x) = \cos x + \sin x$.
b) Một nguyên hàm $F(x) = -\cos x - \sin x$.
c) $\int f(x)dx = -\cos x + \sin x + C$.
d) $f'(x) + f(x) = 2\sin x$.

Câu 15: Cho hàm số $f(x) = (x+5)(x-1)$.

a) $f(x) = x^2 + 4x - 5$.
b) $\int f(x)dx = \frac{x^3}{3} + 2x^2 - 5x + C$.
c) $f'(x) = 2x + 4$.
d) $\int f(x)dx = \int (x+5)dx \cdot \int (x-1)dx$.

Câu 16: Cho $F(x) = e^x + x^3$ là nguyên hàm của $f(x)$.

a) $f(x) = e^x + 3x^2$.
b) $f'(x) = e^x + 6x$.
c) $\int f'(x)dx = e^x + x^3 + C$.
d) $F(1) = e + 1$.
